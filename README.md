# Ghost Application Bot

بوت Discord متكامل للترحيب وتقديم إدارة Ghost والمقابلة الصوتية، جاهز للنشر على GitHub وRailway.

## الوظائف

- ترحيب تلقائي بصورة العضو واسم وبانر السيرفر.
- رول تلقائي للعضو الجديد.
- زر القوانين وزر التقديم داخل رسالة الترحيب.
- التقديم الإداري في الخاص، سؤالًا بعد سؤال.
- إرسال الأسئلة والإجابات إلى روم المراجعة.
- قبول أو رفض بسبب، وإرسال النتيجة للمتقدم في الخاص.
- عند القبول الكتابي يمنح رول المقبول مبدئيًا ويُرسل لانتظار المقابلة.
- بانل مستقل لطلب مراجعة المقابلة الصوتية.
- قبول المقابلة يمنح رول تصريح الدخول، والرفض يطلب سببًا ويرسله في الخاص.
- كنترول لفتح وقفل التقديم وتعديل رسالة الإغلاق ومعرفة الحالة.
- حفظ حالة التقديم في `data.json`.

## 1. ضبط الآيديات

افتح `index.js` وعدّل كل قيمة تبدأ بـ `PUT_`. كل الآيديات موجودة داخل كائن `CONFIG` في أول الملف.

لتفعيل نسخ الآيدي في Discord:

1. افتح User Settings.
2. ادخل Advanced.
3. فعّل Developer Mode.
4. اضغط كليك يمين على السيرفر أو الروم أو الرول ثم Copy ID.

## 2. إعداد البوت في Discord Developer Portal

من صفحة Bot فعّل:

- Server Members Intent
- Message Content Intent

الصلاحيات المطلوبة للبوت:

- View Channels
- Send Messages
- Embed Links
- Read Message History
- Manage Roles

ضع رول البوت أعلى من الرولات التي سيمنحها للأعضاء.

## 3. الرفع على GitHub

أنشئ Repository جديدًا، ثم ارفع جميع ملفات المجلد. لا ترفع ملف `.env` ولا تكتب التوكن داخل `index.js`.

## 4. النشر على Railway

1. اختر New Project ثم Deploy from GitHub Repo.
2. اختر مستودع البوت.
3. افتح Variables وأضف:

   - الاسم: `DISCORD_TOKEN`
   - القيمة: توكن البوت

4. انتظر اكتمال النشر وظهور `Logged in as ...` في Logs.

للحفاظ على حالة فتح وقفل التقديم بعد كل Deploy، أضف Railway Volume على المسار `/data` ثم أضف Variable:

- `DATA_FILE=/data/data.json`

## 5. إرسال البانلات

بعد تشغيل البوت، اكتب الأمر التالي داخل أي روم في السيرفر من حساب إداري:

```text
!panels
```

سيُرسل البوت تلقائيًا:

- بانل التقديم في `APPLY`.
- بانل المقابلة الصوتية في `VOICE_PANEL`.
- بانل الكنترول في `CONTROL`.

استخدم الأمر مرة واحدة فقط حتى لا تتكرر البانلات.

## ملاحظات مهمة

- روابط زر القوانين والتقديم تحتاج `GUILD_ID` وID الرومات بشكل صحيح.
- يجب أن يسمح المتقدم باستقبال الرسائل الخاصة من أعضاء السيرفر.
- مدة كل سؤال 5 دقائق، ويمكن تغييرها من `5 * 60 * 1000` داخل `index.js`.
- يستطيع الأدمن أو أي رول مضاف إلى `STAFF_ROLE_IDS` استخدام أزرار الإدارة.
